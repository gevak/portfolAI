**Overall Concept & Layout**
The website is designed as a dynamic, interactive Gantt chart that spans a single page. The aesthetic mimics a highly polished, futuristic project management tool (like a sci-fi version of Jira or Monday.com) presented in a sleek dark mode. The background features a subtle, faintly glowing grid with vertical columns representing time. As the user scrolls vertically, the timeline advances, and horizontal "task bars" (the projects) animate into view from the left, growing in width to represent their duration. A custom cursor shaped like a crosshair draws animated "dependency arrows" connecting the projects as the user hovers over them.

**Header & Typography**
At the top is a sticky, frosted-glass control bar. The primary typography uses a modern, geometric sans-serif (e.g., Inter or Roboto Mono for technical elements). It prominently features the name **Geva Kipper**, accompanied by the sentence: "Software Engineer at Google, currently building [Insert specific Google work description here]." Directly below this, a glowing, typewriter-effect subtitle reads: *"This website is re-designed each day by AI and is thus ever-changing."* The header also serves as the X-axis of the Gantt chart, with dynamic dates scrolling by as the user moves down the page.

**The Gantt Chart Projects (The 8 Nodes/Lanes)**
Each section is represented as a rounded, neon-colored horizontal bar on the timeline. When a user clicks or hovers over a bar, it smoothly expands downward into a detailed "Project Card" overlaying the grid.

*   **Lane 1: GlglStats** 
    The Gantt bar is styled with a subtle waveform or compression-block pattern. When expanded, the card displays a dynamic data visualization mimicking LZ77 repetition patterns. It contains a neon action button linking to `https://glglstats.geekip.dev` and an embedded, stylized video player for the PyData TLV conference presentation (`https://www.youtube.com/watch?v=jrKAtOsj1Lo`).
*   **Lane 2: Ahuzat Dibuk**
    This bar expands into a card with a background resembling a thermal heat-map gradient. The text details the Tel-Aviv parking scraper. It includes a grid of press links featuring icons for Channel 13 (`https://13tv.co.il/item/news/domestic/internal/parking-902956407/`), Mako (`https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm`), and a classic blue Facebook button for the Secret Tel-Aviv post (`https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/`).
*   **Lane 3: 2D Part Orienting**
    The bar has a geometric, polygonal wireframe motif. Expanding it reveals the C++ computational geometry details, with an animated polygon orienting itself in the background of the card. A monospaced "View Source" button links to `https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/`.
*   **Lane 4: The Turing Jest**
    This section is designed as a split-color arena (e.g., red vs. blue) to represent the LLM head-to-head battles. The card features floating, fading "pun" speech bubbles in the background and a prominent "Enter the Arena" button linking to `https://jest.geekip.dev`.
*   **Lane 5: Rhymes of Israel**
    The Gantt bar opens into a quirky card styled like a torn piece of paper or a retro highschool yearbook page, contrasting playfully with the dark tech theme. It includes a Chrome icon button directing the user to install the extension at `https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb`.
*   **Lane 6: Hatul Basak**
    Designed with a clean, Wikipedia-style serif font layered over the dark mode card. The background features faded trivia question marks. A primary button prompts users to "Play & Create Puzzles," pointing to `https://hatulbasak.geekip.dev`.
*   **Lane 7: The Meta Portfolio**
    This bar pulses with an infinite-loop animation. When expanded, the card shows a miniature, recursive "picture-in-picture" live iframe of the website itself. A self-referential link points to `https://geekip.dev`.
*   **Lane 8: The Milestone (Socials)**
    Instead of a traditional bar, this final item is designed as a glowing "Milestone Diamond"—the standard Gantt chart symbol for project completion. Expanding it reveals a sleek, minimalist dock containing three icon-only links: GitHub (`github.com/gevak`), LinkedIn (`linkedin.com/in/gevakip`), and Facebook (`facebook.com/geva.kipper`).

**Footer & Live AI Status**
Anchored to the absolute bottom of the screen is a persistent, terminal-style status bar. In green monospaced text, it outputs: *"Design generated and actively maintained by [Insert AI Model Name]."* Next to this credit is a live, ticking digital stopwatch displaying the exact hours, minutes, and seconds elapsed since `2026-08-12 01:17:45`, constantly updating via JavaScript to give the site a feeling of being a living, breathing machine.
