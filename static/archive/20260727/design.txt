The website is designed as a single-page, full-screen, top-down view of a sleek, modern hardware synthesizer (reminiscent of teenage engineering devices or an MPC drum machine). Set against a matte dark charcoal background (`#1A1A1A`) with brushed metal textures, the interface relies on tactile CSS 3D effects, neumorphism for the physical buttons, and vibrant, glowing neon accents for active states. The screen is vertically split into two main physical "components": a large, glossy main "LCD Display" screen at the top, and an interactive 4x2 grid of chunky synth pads (the keys) at the bottom. The mouse cursor is styled as a quarter-inch audio jack plug.

The top Header acts as the synthesizer’s branded facade. Embedded in a subtle metallic bevel is a glowing, retro-digital typography reading "Geva Kipper". Just below it, styled like printed hardware specs, is a crisp sans-serif sentence: "Currently architecting and engineering software solutions at Google." Above the main LCD screen, a scrolling, amber-colored LED ticker tape reads: "SYSTEM NOTIFICATION: This website's design is regenerated daily by AI. You are experiencing a transient, ever-changing interface."

The top "LCD Display" is the central viewing area. By default, it displays a steady, green glowing oscilloscope waveform. When the user interacts with the synthesizer pads below, this screen instantly crossfades to display the selected project's information, styled like an operating system terminal or a futuristic dashboard, complete with relevant data visualizations, typography, and glowing hyperlink buttons.

The bottom half of the screen contains 8 massive, tactile synthesizer pads arranged in a 2x4 grid. Each pad serves as an interactive project trigger. Hovering over a pad causes it to physically "tilt" using CSS 3D transforms. Clicking or pressing a pad achieves three things: it visually depresses into the board (box-shadow inset), it triggers a distinct, pitch-shifted synth note or drum beat (via web audio), and it instantly loads the corresponding content into the top LCD screen. The 8 pads map to the content as follows:

**Pad 1 (Yellow Glow - GlglStats):** Clicking plays a heavy bass kick. The LCD projects a retro audio wave visualizing LZ77 compression patterns inside Israeli pop songs. The text details the Python-based repetition measurement project. Below the description are two tactile toggle buttons linking to the live site (https://glglstats.geekip.dev) and the PyData TLV presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo).

**Pad 2 (Red Glow - Ahuzat Dibuk):** Clicking plays a crisp snare. The LCD shifts to a pixelated, red-to-blue thermal heatmap aesthetic. It describes the Python scraping and data visualization project for Tel-Aviv parking lot occupancy. Glowing data-nodes link out to coverage on Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and Secret Tel-Aviv (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

**Pad 3 (Blue Glow - 2D Part Orienting):** Clicking triggers an echoing synth pluck. The display features a rotating geometric wireframe of a polygon. The text presents the open-source C++ computational geometry implementation for algorithmic push plans, accompanied by a digital button linking to the TAU index (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).

**Pad 4 (Purple Glow - The Turing Jest):** Clicking activates a warped, comedic slide-whistle synth sound. The LCD takes on a split-screen arcade fighting game layout ("LLM vs LLM"). The copy explains the LMSYS-like arena for rating AI pun explanations, featuring a flashing "ENTER ARENA" button pointing to https://jest.geekip.dev.

**Pad 5 (Orange Glow - Rhymes of Israel):** Clicking triggers a rhythmic hi-hat sequence. The content area switches to an animated highschool yearbook doodle style. It outlines the LLM-powered Chrome extension that rewrites news headlines into comedic rhymes. A stylized "Install Extension" decal links to the Chrome Web Store (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

**Pad 6 (Green Glow - Hatul Basak):** Clicking plays an 8-bit retro gaming coin sound. The screen shows a chaotic collage of Wikipedia-style text blocks and trivia question marks, introducing the Hebrew catfishing.net trivia port, its AI-generated daily challenges, and user-puzzles. A massive "PLAY NOW" arcade button links to https://hatulbasak.geekip.dev.

**Pad 7 (Cyan Glow - The Meta Project):** Clicking triggers an endless, repeating delay effect. The screen visually descends into an infinite mirror illusion. The text playfully admits the self-referential nature of presenting the very portfolio website the user is currently using, with a link looping right back to https://geekip.dev.

**Pad 8 (White Glow - Social Patchbay):** Clicking plays a satisfying mechanical "clack" of cables plugging in. The LCD turns into a visual patchbay with twisting audio cables connecting into input jacks. Text labels next to the jacks provide direct outbound connections to github.com/gevak, linkedin.com/in/gevakip, and facebook.com/geva.kipper.

At the very bottom edge of the synthesizer board lies a secondary, slim LED readout strip, representing the footer. On the left side, printed in a tiny, futuristic monospace font, is the hardware credit: "MANUFACTURED BY AI MODEL: ChatGPT-4" (or the respective engine rendering this). On the right side of this strip flashes a digital, red-segmented stopwatch continuously ticking up in real-time, functioning via Javascript, reading: "SYSTEM UPTIME SINCE 2026-07-27 02:13:38 // [HH]:[MM]:[SS]".
