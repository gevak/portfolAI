The overarching visual theme is "Bioluminescent Cyber-Ocean." The website is a single-page, fluid viewport with a deep dark-mode background—transitioning from deep navy blue to pitch black. The central element is a highly interactive, fluidly animated octopus designed with a modern glassmorphism aesthetic, featuring glowing, neon-colored internal wiring that gives it an AI/technological vibe. The tentacles respond to cursor movements with realistic, physics-based swaying.

At the center of the viewport, resting inside or floating just above the translucent head of the octopus, is the main typography. It displays the name **Geva Kipper** in a bold, modern sans-serif font. Directly beneath is the sentence: "Software Engineer currently building and solving challenges at Google." Below this, written in an elegant, glowing, and slightly pulsating italic font, is the subtitle: *"This website is re-designed each day by AI and is thus ever-changing."* 

Radiating from the central octopus are eight distinct tentacles, each terminating in a glowing orb. On hover, the orb unfurls into a sleek, frosted-glass project card. When a user clicks a tentacle, the octopus smoothly pulls that specific card to the center of the screen, enlarging it for readability while slightly dimming and blurring the background and other tentacles. The eight tentacles hold the following sections:

**Tentacle 1 (Neon Pink - GlglStats):** The card background features a subtle, animated audio waveform. It details the Python project measuring the repetitiveness of Israeli pop-chart songs using LZ77 compression and visualizing the patterns. The card includes two glowing, pill-shaped buttons: one linking to the live site (https://glglstats.geekip.dev) and another styled with a play icon linking to the PyData TLV presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo).

**Tentacle 2 (Amber Orange - Ahuzat Dibuk):** Visualized with a miniature, heat-map gradient background. The text explains the Python scraping and data visualization project for Tel-Aviv parking lot occupancy. It features a row of media icons linking to news coverage on Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/) and Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), plus a Facebook icon linking to the original Secret Tel-Aviv publication (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

**Tentacle 3 (Electric Blue - 2D Part Orienting):** This card has slowly rotating, wireframe polygons in its background. It presents the C++ computational geometry library implementation of a push-plan algorithm for orienting polygons. A prominent link directs users to the code and documentation (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).

**Tentacle 4 (Neon Purple - The Turing Jest):** Thematic elements include robotic theater masks. The card describes the LMSYS-like arena where LLMs compete to make and explain puns, judged by users. A sleek call-to-action button invites users to judge the puns, linking to https://jest.geekip.dev.

**Tentacle 5 (Mint Green - Rhymes of Israel):** Styled subtly like a digital newspaper covered in high-school yearbook doodles. It explains the Chrome extension that utilizes an LLM to rewrite Israeli news headlines into comedic rhymes. It includes a download button pointing to the Chrome Web Store (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

**Tentacle 6 (Cyan - Hatul Basak):** Features a subtle silhouette of a cat made of puzzle pieces. It outlines the Hebrew port of the Wikipedia-based trivia game, highlighting the daily AI-generated challenges and user-created themed puzzles. A play button links to the game site (https://hatulbasak.geekip.dev).

**Tentacle 7 (Magenta - The Meta Portfolio):** Decorated with an animated infinity loop or recursive spiral, this card playfully acknowledges the self-referential nature of the portfolio website itself, holding a prominent link back to https://geekip.dev.

**Tentacle 8 (Silver/White - Connections):** The networking tentacle. Instead of a text-heavy project, this card elegantly displays three large, interactive 3D icons. Hovering over each triggers a distinct animation before allowing the user to click out to GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper).

Anchored fixedly to the bottom of the screen is a minimalist, translucent command bar representing the "ocean floor." On the left side of this bar is a clean typography credit acknowledging the AI model as the daily designer of the site. On the right side is a live, ticking digital stopwatch utilizing a glowing monospace font. This timer dynamically counts up, displaying the exact hours, minutes, and seconds that have elapsed since the precise timestamp of **2026-08-08 01:04:57**, giving the site an ongoing, living pulse.
