**Global Aesthetic & Architecture**
The website is a single-page application utilizing modern CSS grid, 3D transforms, and glassmorphism to transform the entire viewport into the front face of a sleek, retro-futuristic digital vending machine. The background is a moody, blurred neon atmosphere (dark midnight blue with ambient magenta and cyan glows), pushing the physical machine into the foreground. The machine features a brushed metal texture, a large inset glass panel with subtle specular reflections (`backdrop-filter`), a glowing numeric keypad on the right, and a heavy delivery chute at the bottom. The UI is elegant yet highly interactive, heavily relying on hover states, sound-effect cues, and smooth CSS drop animations. 

**Header & Branding (The Machine Canopy)**
At the top of the vending machine sits a backlit, glowing acrylic marquee. In elegant, modern typography, it displays the developer's name: "Geva Kipper". Just below the name is a sleek, illuminated subtitle reading: "Currently building scalable software solutions and driving technical innovation at Google." 
Wrapping the bottom edge of this canopy is a classic LED dot-matrix scrolling ticker (using CSS marquee animations) that reads: *"NOTICE: This digital portfolio is re-designed each day by AI and is thus an ever-changing experience."*

**The Glass Display & Snack Grid (The Projects)**
Behind the glass, the 8 portfolio sections are arranged in a 4x2 grid on metallic spring coils. Each project is visually represented as a distinct, 3D-styled snack or beverage package. 

*   **Slot A1 - GlglStats:** Designed as a bag of "Pop-Chips" with a vibrant, rhythmic sound-wave graphic on the bag. 
*   **Slot A2 - Ahuzat Dibuk:** Designed as a sleek matchbox or tin with a red-to-yellow thermal heatmap gradient over a stylized map of Tel-Aviv.
*   **Slot A3 - 2D Part Orienting:** Designed as a transparent, hard-plastic geometric puzzle cube displaying a polygon inside.
*   **Slot A4 - The Turing Jest:** Designed as a theatrical, gold-foil-wrapped chocolate bar featuring two overlapping comedy tragedy masks. 
*   **Slot B1 - Rhymes of Israel:** Designed as a retro milk carton featuring a "Highschool Yearbook" photo and a rhyming speech bubble.
*   **Slot B2 - Hatul Basak:** Designed as a gourmet tin of cat food or sardines, featuring an elegant, inquisitive cat silhouette.
*   **Slot B3 - The Portfolio Site:** Designed as an "Infinity Energy" drink can; the label features a recursive, mirror-droste effect of the vending machine itself.
*   **Slot B4 - The Socials:** Designed as a colorful "Variety Pack" cardboard sampler box displaying the logos for GitHub, LinkedIn, and Facebook.

**Interactive Mechanics (Hover & Dispense)**
When the user hovers over any snack, the machine's internal neon lighting focuses on that item, and the digital LCD screen above the keypad on the right types out the project's title and a brief hook. 
When a user clicks a snack, a JavaScript-triggered CSS animation plays: the metal coil spins, the snack drops, bounces off the glass, and falls into the dark delivery chute at the bottom. The chute then glows and slides open, expanding an elegant modal overlay across the screen.

**The "Dispensed" Project Views (Modal Details)**
Inside the modal, the selected snack floats on the left, slowly rotating in 3D. On the right, styled like a slick "Nutritional Facts" or "Ingredients" label, the project details and links are displayed:

1.  **GlglStats:** The text details a Python project measuring the repetitiveness of Israeli pop-chart songs using LZ77 compression and visualizing repetition patterns. "Ingredients" (links) include the live site (`https://glglstats.geekip.dev`) and a PyData TLV presentation video (`https://www.youtube.com/watch?v=jrKAtOsj1Lo`).
2.  **Ahuzat Dibuk:** The text describes a Python scraping and data visualization project generating heat-maps of Tel-Aviv car parking lot occupancies. Links feature news coverage (`https://13tv.co.il/item/news/domestic/internal/parking-902956407/` and `https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm`) and the original Facebook publication (`https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/`).
3.  **2D Part Orienting:** The text explains a C++ implementation within an open-source computational geometry library for constructing a 'push plan' to orient a polygon. The link points to the source and info (`https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/`).
4.  **The Turing Jest:** The text describes an LMSYS-like arena where LLMs compete in making and explaining puns, rated by users. The link points to the arena (`https://jest.geekip.dev`).
5.  **Rhymes of Israel:** The text details a Chrome extension using an LLM to rewrite Israeli news headlines into comedic highschool yearbook rhymes. The link points to the Chrome Web Store (`https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb`).
6.  **Hatul Basak:** The text outlines a Hebrew port of a Wikipedia-based Trivia game featuring AI-generated daily challenges and user-created themed puzzles. The link directs to the game (`https://hatulbasak.geekip.dev`).
7.  **Portfolio Website:** The text makes a meta, self-referential joke about the vending machine site currently being viewed. The link points recursively to the site itself (`https://geekip.dev`).
8.  **Socials:** The text provides a friendly invitation to connect. Links are styled as prominent buttons pointing to GitHub (`github.com/gevak`), LinkedIn (`linkedin.com/in/gevakip`), and Facebook (`facebook.com/geva.kipper`).

**Footer & Timekeeping (The Machine Base)**
At the very bottom of the vending machine, etched into a dark, vented metallic kickplate, is the site's footer. It features subtle, low-opacity typography that reads: *"Machine engineered and designed by an AI Model."* 
Right beside this credit is an embedded digital red-LED stopwatch. Using JavaScript, this timer actively counts up, displaying the exact hours, minutes, and seconds that have elapsed since the precise timestamp: `2026-08-02 02:05:15`.
