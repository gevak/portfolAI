**Global Aesthetic & Layout Strategy**
The website utilizes a sleek, dark-mode "Cyber-Science" aesthetic, characterized by a deep graphite background (`#121212`) accented with vibrant neon colors (electric blue, neon green, magenta, and bright yellow). The entire single-page application is structured visually as an asymmetrical, interactive Periodic Table of Elements using a CSS Grid. Instead of chemical elements, the columns and groups categorize your known programming languages and technologies (e.g., a Python column, a C++ column, a Web/JS column, an AI/LLM column). The grid is populated by faint, muted "filler" blocks representing various languages and tools you know, but the core interactive UI consists of 8 oversized, brightly glowing "Element Blocks" representing your projects and links. 

**Header & Typography**
Positioned organically in the top-left "empty space" of the periodic table (where the Alkali metals gap usually is), the header features your name, "Geva Kipper," in a bold, modern sans-serif typeface (like Inter or Roboto) with a subtle metallic gradient. Beneath it, a clean, monospaced sentence reads: "Software Engineer currently solving complex problems at Google." Below this is the AI-redesign subtitle, styled with a slight, continuous color-shifting CSS animation to emphasize its ephemeral nature: *"Notice: This website's UI is uniquely re-designed each day by AI and is thus ever-changing."*

**The Interactive Periodic Table (Main UI)**
The 8 required sections are designed as prominent "Isotopes" or active element cards on the table. Each block features an Atomic Number (1-8), a stylized two-letter symbol (e.g., `Gl` for GlglStats, `Ah` for Ahuzat Dibuk), the project name, and an atomic weight representing lines of code or hours spent. The background color of each block corresponds to its primary programming language category. When a user hovers over an element, it pulses with a neon glow. When clicked, a seamless FLIP animation expands the block into a large, glassmorphic (frosted glass) modal overlaid on the dimmed table, revealing the deep-dive content.
