The overall aesthetic of the website is a "neo-retro" operating system, marrying the nostalgic visual language of classic 90s graphical interfaces (like Windows 95 or classic Mac OS) with smooth, modern CSS animations and layout principles. The screen acts as a full-viewport "desktop environment" with a subtly animated CRT scanline overlay, a nostalgic teal or muted-gray background color, and crisp, pixel-perfect 3D inset/outset borders. Typography relies on a clean, legible monospaced or pixel-art font for UI elements, paired with standard sans-serif for heavier reading within the application windows. 

Upon loading, a persistent "System Properties" window sits neatly in the center of the desktop. The title bar reads "User Profile." Inside this window is the developer's name, Geva Kipper, in a bold, stylized header, followed by a single sentence: "Software Engineer at Google building and optimizing scalable web systems." Directly beneath this, styled as a glowing terminal-green "System Warning" marquee or text block, is the subtitle: "Notice: This environment is procedurally re-designed each day by an AI model, ensuring an ever-changing, ephemeral architecture." This window cannot be closed, serving as the permanent anchor for the user's identity.

The primary content is distributed across eight interactive desktop icons, arranged neatly on a grid. Clicking an icon instantly opens a draggable, minimizable "application window" modal, complete with classic close/minimize buttons on the top right bar and a z-index manager to bring active windows to the front. 

The eight project windows are designed as follows:
Window 1 is titled "GlglStats.exe" and uses a retro bar-chart icon. Inside, it explains the Python/LZ77 Israeli pop-chart repetitiveness project with a hyperlink styled as a vintage blue-underlined text to https://glglstats.geekip.dev. Below the text, the PyData TLV presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo) is embedded within a customized iframe designed to look like a vintage multimedia player.
Window 2 is "Ahuzat_Dibuk.dat" (a car icon), detailing the Tel-Aviv parking data scraping and heatmap generation. Its layout mimics a news directory, featuring three distinct "read more" buttons pointing to the 13tv broadcast (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), the Mako article (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and the original Facebook publication (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).
Window 3 is "2D_Part_Orienting.cpp" (a geometric polygon icon). When opened, it resembles a dark-mode code editor with C++ syntax highlighting, explaining the push-plan algorithm implementation for an open-source computational geometry library, concluding with a "Run Executable" button linking to https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/.
Window 4 is "The_Turing_Jest.app" (a jester hat icon). The window presents a split-pane layout mimicking an arena battle, explaining the LMSYS-style LLM pun competition and user rating system, with a prominent "Enter Arena" link directing to https://jest.geekip.dev.

Window 5 is "Rhymes_of_Israel.crx" (a newspaper icon). It describes the LLM-powered Chrome extension that transforms Israeli news headlines into highschool yearbook-style comedic rhymes. The link to install the extension (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb) is styled as a chunky, satisfying 90s "Download / Install" dialog button.
Window 6 is "Hatul_Basak.exe" (a pixelated cat icon). The interior looks like a retro trivia game menu, detailing the Hebrew port of catfishing.net, the Wikipedia trivia format, the AI-generated daily challenges, and user-generated puzzles. A "Start Game" link directs the user to https://hatulbasak.geekip.dev.
Window 7 is titled "Portfolio.html" and uses a recursive icon of the desktop itself. The window contains meta-humor about presenting the exact portfolio site the user is currently looking at, including a self-referential hyperlink to https://geekip.dev.
Window 8 is titled "Network_Neighborhood" (a classic connected computers icon). Opening it reveals an address-book-style layout containing the social links: an icon for GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper).

Spanning the bottom of the viewport is the OS "Taskbar." It features a "Start" menu button (which, when clicked, reveals a vertical list of the same eight sections for alternative navigation) and active tabs for whichever windows are currently open. In the center of the taskbar, seamlessly integrated into the UI, is an engraved text field reading: "Design architected by: LLM Artificial Intelligence." Finally, in the bottom right corner—exactly where the classic system clock would be—is a live JavaScript stopwatch. Instead of the current time, this digital clock actively ticks upwards (in Hours:Minutes:Seconds), displaying the exact duration of time that has elapsed since the temporal anchor point of 2026-08-20 00:50:38.
