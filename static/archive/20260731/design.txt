The initial state of the website loads entirely covered in an interactive front layer of "digital smog"—a chaotic, semi-opaque canvas of glitching pixels, overlapping obsolete code snippets, gray noise, and fragmented pseudo-ads. The user's cursor (or finger on mobile) acts as a digital squeegee. As they drag across the screen, the cursor wipes away the smog in real-time using a dynamic mask-image or HTML5 Canvas composite operation. A soft neon-blue particle trail follows the cursor's edge, making the physical motion of scrubbing feel highly tactile and satisfying. Once the user scrubs away exactly 50% of the smog covering, a smooth CSS animation triggers: a digital "wind" blows the remaining smog off the edges of the screen, permanently revealing the pristine, elegant portfolio beneath.

The exact opposite of the chaotic smog, the underlying interface features an ultra-clean, minimalist "glassmorphism" aesthetic. The color palette relies on a deep, expansive midnight-blue animated gradient background, allowing the content to float on translucent, polished glass cards with subtle borders and soft drop-shadows. At the top of the single page rests the header, featuring crisp, modern typography. It boldly declares the developer's name: **Geva Kipper**. Right below, an elegant subtitle reads: "Currently shaping the future of tech as a Software Engineer at Google." A secondary, actively typing or softly pulsing monospace string sits beneath this, stating: "Notice: This website is fundamentally re-designed each day by AI and is thus ever-changing."

Below the header, the layout transitions into an asymmetric masonry grid of eight distinct interactive project cards. When hovered, each card’s glass background slightly clarifies and tilts smoothly toward the user's cursor using a 3D transform effect. 

The first card features **GlglStats**, themed with abstract audio waveforms. It describes the Python project measuring the repetitiveness of Israeli pop-chart songs using LZ77 compression and visualizing repetition patterns in famous songs. Minimalist buttons link out to the live site at https://glglstats.geekip.dev and a YouTube play icon links to the PyData TLV presentation at https://www.youtube.com/watch?v=jrKAtOsj1Lo. 

The second card highlights **Ahuzat Dibuk**, adorned with a dynamic SVG heatmap motif of Tel Aviv. It details the Python scraping and data visualization project tracking parking lot occupancy for residents. This card contains a structured row of link icons pointing to the news coverage on Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and the original viral Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

The third card, **2D Part Orienting**, displays a wireframe polygon that slowly rotates inside the card. It presents the C++ algorithm implemented in an open-source computational geometry library to construct push plans to orient polygons. A sleek link directs to the research and code: https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/. 

The fourth card showcases **The Turing Jest**, styled with a split-face icon (half robot, half comedy mask). It introduces the LMSYS-like arena where LLMs compete at making and explaining puns, rated by users, with a centralized link to https://jest.geekip.dev.

The fifth and sixth cards sit side-by-side. **Rhymes of Israel** is styled like a digitized, scribbled high school yearbook page, presenting the Chrome extension that applies an LLM to rewrite Israeli news headlines into comedic rhymes. A stylized download button links to https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb. **Hatul Basak** uses a pixel-art cat avatar over a Wikipedia puzzle globe backdrop. It introduces the Hebrew port of catfishing.net—an AI-driven daily trivia game with user-generated components, linking directly to https://hatulbasak.geekip.dev.

The final row containing the seventh and eighth cards grounds the portfolio. The seventh card presents the **Meta Portfolio Project**, stylized with an infinite-mirror optical illusion or an infinite recursion code loop, stating that this very portfolio is one of the distinct projects, and providing a self-referential link to https://geekip.dev. The eighth and final card acts as a sleek social hub. Devoid of heavy text, it features three oversized, perfectly centered neon icons acting as links to GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper).

At the very bottom of the page sits a minimalist footer, aligned to the center. Rendered in a glowing, futuristic monospace font, a text line reads: "Website layout and concept dynamically generated by an AI Language Model." Just below it is a live, ticking digital stopwatch interface calculating the exact hours, minutes, and seconds that have passed since the timestamp `2026-07-31 02:07:08`. The counter flips smoothly like an old train station board, contrasting beautifully with the otherwise highly futuristic glass-and-neon aesthetic of the site.
