**Global Aesthetic & Architecture**
The website is a single-page, full-screen interactive web application heavily inspired by modern issue-tracking tools like Linear or Trello, but elevated through a "Dark Mode Cyber-Glass" aesthetic. The background is a deep, obsidian black featuring a slow-moving, generative fluid mesh gradient in subtle Google-inspired hues (muted blues, reds, and yellows) that softly shift in the background, reinforcing the concept of an active, AI-driven entity. The layout takes up the entire viewport with no vertical scrolling on the body; instead, the UI is divided into a fixed header, a horizontal-scrolling central Kanban board, and a fixed footer. 

**Header (The Control Center)**
At the top of the screen sits a sleek, frosted-glass header with a blur backdrop. On the left side, the developer's name, "Geva Kipper," is displayed in a bold, elegant sans-serif font. Directly beneath it is a crisp, single-sentence subtitle: "Software Engineer at Google, crafting scalable systems and impactful products." On the right side of the header, designed to look like a live system-status terminal, is a secondary subtitle written in a glowing green monospaced font: "System Note: This website's design is hallucinated and re-rendered daily by AI. Expect shifting paradigms."

**The Interactive Kanban Board (Main Content Area)**
The core of the site is a fully interactive, draggable Kanban board taking up the center of the screen. The board features four vertical columns titled with software development lifecycle stages: "Backlog," "In Progress," "Code Review," and "Deployed." By default, the eight project boxes are randomly distributed across these columns, but the user is free to drag, drop, and reorganize the cards across any column. The drag-and-drop interaction should feel physical and snappy, utilizing modern JavaScript physics to slightly tilt the cards as they are picked up and drop them with a subtle haptic-style visual snap.

**The Task Cards (The Projects)**
The eight sections are designed as sleek "Task Cards." Each card features a dark-grey background, rounded corners, a subtle drop shadow, and a top border that glows on hover. Each card includes a "tag" in the top left (e.g., Python, C++, LLM), a bold title, a brief descriptive body, and row of modern, pill-shaped buttons containing the project links and icons.

*   **Card 1:** Tagged "Python". Title: "GlglStats". The body explains it is a project measuring the repetitiveness of Israeli pop-chart songs based on LZ77 compression, visualizing repetition patterns in famous songs. It contains two action buttons: one linking to the live site (https://glglstats.geekip.dev) and another linking to a PyData TLV presentation video (https://www.youtube.com/watch?v=jrKAtOsj1Lo).
*   **Card 2:** Tagged "DataViz". Title: "Ahuzat Dibuk". The body describes a Python scraping and data visualization project that collects statistics on Tel-Aviv parking lot occupancy to generate heat-maps for residents. It features an array of press-link buttons: Channel 13 News (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and the original Secret Tel-Aviv Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).
*   **Card 3:** Tagged "C++". Title: "2D Part Orienting". The description highlights a C++ implementation within an open-source computational geometry library of an efficient algorithm to construct a 'push plan' for orienting a polygon. A button links to the project and code (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).
*   **Card 4:** Tagged "LLM". Title: "The Turing Jest". The body details an LMSYS-like arena where LLMs compete at making and explaining puns, rated by users. A primary button links to the arena (https://jest.geekip.dev).
*   **Card 5:** Tagged "Chrome Extension". Title: "Rhymes of Israel". The text explains an LLM-powered extension that rewrites Israeli news headlines into comedic, highschool yearbook-style rhymes. A button directs to the Chrome Webstore (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).
*   **Card 6:** Tagged "AI Trivia". Title: "Hatul Basak". Described as a Hebrew port of catfishing.net and Wikipedia-based trivia game utilizing AI for daily challenges, plus user-generated themed puzzles. A button links to play and create puzzles (https://hatulbasak.geekip.dev).
*   **Card 7:** Tagged "Meta". Title: "Portfolio Website". The text breaks the fourth wall, noting this is a self-referential project—the exact site the user is currently interacting with. A self-reference button links back to the root (https://geekip.dev).
*   **Card 8:** Tagged "Networking". This card breaks the standard visual mold, featuring a subtle iridescent background. It serves as the contact and social hub, containing stylized icon-buttons for GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper).

**Footer (AI Credit & Temporal Diagnostics)**
Pinned to the bottom of the viewport is a minimalist footer bar. On the left side, formatted like a terminal output log, reads the credit: "Rendered and conceptualized by: AI Language Model." On the right side, anchored by a small clock icon, is a live JavaScript stopwatch utilizing a monospaced digital font. It actively ticks upward in real-time, displaying the exact hours, minutes, and seconds that have elapsed since the epoch timestamp: "2026-08-22 00:50:58".
