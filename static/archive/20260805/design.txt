The overall aesthetic is a "Modern Antique Cartography" experience—a single-page, vertical-scrolling interactive pirate treasure map. The background is a rich, dark-themed digital parchment with subtle, animated topographical lines, water ripples, and faded sea monsters. As the user scrolls, a glowing, dashed gold line dynamically draws itself down the page, acting as the main narrative thread that connects various "islands" and "landmarks" (the sections). The design should balance high-end elegance—using gold foil accents, crisp vector illustrations, and sleek typography—with playful pirate motifs. 

At the top of the page, acting as the map’s ornate "Legend," is the header. It features the name **Geva Kipper** written in an elegant, modern calligraphy font. Below it, a clean sans-serif sentence reads: "Software Engineer currently navigating the vast digital oceans and shaping technical currents at Google." Just beneath this is a visually distinct, slightly glowing subtitle housed in a tattered ribbon banner: "This parchment is a living document, re-designed each day by AI, forever altering its shores and secrets." An animated compass rose sits in the corner, tracking the user's mouse movements.

The user's journey along the dashed gold line takes them through eight distinct geographical landmarks, serving as the project boxes. Each "box" is an interactive coastal region or island. When hovered over, the islands slightly elevate using CSS transform effects, and hidden details like palm trees or tiny waves animate. 

**Stop 1: The Isle of Echoes (GlglStats)** 
Designed as an island shaped like a mesmerizing, repeating spiral to represent LZ77 compression. The description explains the Python project measuring the repetitiveness of Israeli pop-chart songs and visualizes these patterns. The section features two interactive elements: an elegant spyglass icon that links directly to the project (https://glglstats.geekip.dev), and an embedded antique frame that plays the PyData TLV conference presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo) upon clicking.

**Stop 2: The Crowded Docks (Ahuzat Dibuk)** 
Visualized as a dense, heavily populated port city on the map. The map features glowing heat-map lanterns highlighting parking occupancy. The text details the Python scraping and data visualization project for Tel-Aviv parking lots. Scattered around the docks are "messages in bottles" and "news scrolls" that link out to the project’s coverage: Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and the Secret Tel Aviv Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

**Stop 3: Geometry Gulf (2D Part Orienting)** 
This region is drawn with sharp, precise, polygonal coastlines and algorithmic grids fading into the water. It details the C++ implementation within an open-source computational geometry library for constructing a polygon push plan. A golden protractor icon serves as the interactive link to the code and additional info (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).

**Stop 4: The Jester’s Peninsula (The Turing Jest)** 
A gladiator-style colosseum built on a rocky peninsula, flanked by a laughing skull and crossbones. This section presents the LMSYS-like arena where LLMs compete in making and explaining puns, rated by the crew (users). A grand, wooden gateway serves as the link to enter the arena (https://jest.geekip.dev).

**Stop 5: Rhymers' Reef (Rhymes of Israel)** 
Depicted as a mysterious, glowing coral reef surrounding a sunken ship with sails made of newspaper clippings. The text explains the Chrome extension using an LLM to rewrite Israeli news headlines into comedic, high-school yearbook-style rhymes. A shiny, animated pearl inside an oyster serves as the button to install the extension (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

**Stop 6: Cat-Fish Cove (Hatul Basak)** 
A bay subtly shaped like a feline's silhouette, with tiny digital fish jumping out of the drawn waters. This section describes the Hebrew port of catfishing.net, an AI-generated Wikipedia-based trivia game featuring both daily and user-created challenges. A fishing rod hovering over the water holds a bait icon that links to play the game and create puzzles (https://hatulbasak.geekip.dev).

**Stop 7: The Meta Maelstrom (Portfolio)** 
A beautifully animated, swirling vortex on the map. It holds a miniature, recursive reflection of the treasure map itself. The description cheekily presents the meta-project of building this exact portfolio website. Clicking the eye of the whirlpool loops the user to the self-reference link (https://geekip.dev).

**Stop 8: Treasure Island (Socials)** 
The end of the dashed gold line culminates in a giant, glowing red 'X'. Beneath it is an open, overflowing treasure chest. Instead of standard social icons, the chest is filled with intricately minted gold doubloons and gemstones. Hovering over specific coins reveals the logos and links to GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper).

At the very bottom of the page, acting as the mapmaker's signature, is a beautifully rendered antique chronometer (a nautical stopwatch). Inside the brass casing, digital numbers tick continuously, showing the exact hours, minutes, and seconds passed since 2026-08-05 01:53:34. Beside the chronometer, written in a faded ink script, is a credit line: "Map charted, generated, and maintained by the AI Model navigating the digital winds."
