The global aesthetic for the website is a moody, elegant "neon on obsidian" dark mode, utilizing heavy glassmorphism and real-time 3D rendering. The single-page layout is locked to the viewport (scroll-jacking or fixed scroll), transforming the user's mouse wheel or swipe gestures into a z-axis 3D navigation rather than traditional vertical scrolling. The background is a pitch-black abyss illuminated by subtle, slowly shifting, out-of-focus neon gradients that react loosely to mouse movement.

At the absolute top of the screen, a frost-glass header floats permanently. It features the developer’s name, "Geva Kipper," in a bold, oversized, geometric sans-serif font. Directly below it, written in a crisp monospace font, is the bio: "Software Engineer at Google, engineering large-scale, high-impact systems." A shifting, holographic subtitle glows underneath it with the text: "This environment is re-designed each day by AI and is in a state of eternal evolution."

The core mechanism of the site is the "Push Over" 3D card interaction. In the center of the viewport, eight oversized, translucent glass cards stand upright, stacked one behind the other like a row of dominos receding into the digital distance. When the user scrolls down, an invisible physical force "pushes" the front-most card. Using modern CSS 3D transforms and JavaScript physics, the front card rotates dynamically on its bottom X-axis, physically falling backward until it lies completely flat, fading into the floor to reveal the next card. Each active, standing card tracks the user's cursor with a subtle 3D parallax tilt, making the content feel tangible and interactive.

Each of the eight standing cards acts as an isolated project capsule with distinct internal styling reflecting its theme:
Card 1 (GlglStats) features dynamic, glowing audio-wave visualizations in the background. It displays the project description prominently, flanked by two pill-shaped buttons: one linking to the live site at https://glglstats.geekip.dev, and another stylized as a YouTube play button launching the PyData TLV presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo).
Card 2 (Ahuzat Dibuk) is textured with a fragmented, glowing red-to-green heat-map of Tel Aviv. The text explains the parking data scraping, while the footer of the card features media logos functioning as links to the Channel 13 and Mako news broadcasts, alongside a stylized Facebook icon for the Secret Tel Aviv launch post.
Card 3 (2D Part Orienting) shifts to a stark, wireframe geometric aesthetic. An animated polygon continuously orienting itself rests behind the text. A sleek button links out to the CGAL implementation and additional code at https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/.
Card 4 (The Turing Jest) splits down the middle, visually resembling a colorful boxing ring or arena (red versus blue). The explanation of the LLM pun arena overlays the center, with a bold "Enter Arena" button linking to https://jest.geekip.dev.

Card 5 (Rhymes of Israel) breaks the digital pattern by embedding a torn, scribbled high-school yearbook texture inside the glass card. The headline comedy extension is explained with playful, rhyming typography, and a prominent badge links directly to the Chrome Web Store extension page natively.
Card 6 (Hatul Basak) merges a rigid Wikipedia-style grid layout with playful, abstract cat iconography. The explanation of the daily AI trivia challenges and user puzzles sits above an interactive-looking button linking directly to https://hatulbasak.geekip.dev.
Card 7 (The Portfolio Site) features a "meta" infinity-mirror visual effect, receding endlessly into the center of the card. The text references the site the user is currently viewing, with a self-referencing glow link to https://geekip.dev.
Card 8 (The Social Finale) has no background texture, opting instead for pure, high-gloss clarity. Three massive, 3D-rendered icons float inside the card: GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper). Hovering over these icons makes them spin, offering a clean exit point for the user.

Fixed to the absolute bottom of the viewport is a minimalist, glowing footer bar. On the left side, it displays text crediting the AI model responsible for the day's design iteration. On the right side, a live, ticking JavaScript digital stopwatch continuously counts up (in hours, minutes, and seconds format), displaying exactly how much time has passed precisely since the temporal anchor of 2026-07-25 02:02:12, grounding the ever-changing AI theme in a tangible, unstoppable flow of time.
