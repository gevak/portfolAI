The website will be a full-viewport, fully functional simulation of a classic Windows 95 desktop. The background is a solid retro teal (`#008080`), acting as the canvas for a workspace of draggable, interactable application windows. The interface will heavily use CSS-drawn 3D borders (classic light/dark gray inset and outset techniques) and pixelated typography like "MS Sans Serif" to ensure absolute era-accuracy, while running on modern HTML, JavaScript, and CSS.

In the center of the desktop, an unclosable, prominent dialog box titled "Welcome.exe" (resembling the classic Windows System Properties window) introduces the developer. Next to a 32x32 pixel-art avatar, bold text displays "Geva Kipper", followed by a line reading: "Currently engineering solutions at Google." Below this, styled as a classic "Tip of the Day" with a yellow lightbulb icon, is the subtitle: "Note: This website is re-designed each day by AI and is thus ever-changing." 

Scattered and cascaded across the desktop are eight distinct program windows, each styled to match a specific 1990s software aesthetic and featuring classic dark-blue title bars with minimize, maximize, and 'X' buttons:

**Window 1: GlglStats.exe**
Styled as a hybrid between MS-DOS Command Prompt and classic Windows Media Player. The terminal section contains the project description: a Python tool measuring the repetitiveness of Israeli pop-chart songs using LZ77 compression and visualizing the patterns. Below the description is a direct link to `https://glglstats.geekip.dev`, next to an embedded, retro-framed YouTube player presenting the PyData TLV conference talk: `https://www.youtube.com/watch?v=jrKAtOsj1Lo`.

**Window 2: Ahuzat_Dibuk.folder**
Designed as an open File Explorer window. The top panel explains the Python scraping and data visualization project that collects Tel-Aviv parking lot occupancy data for resident heat-maps. Inside the folder view are three classic document icons linking to the media coverage: Channel 13 (`https://13tv.co.il/item/news/domestic/internal/parking-902956407/`), Mako (`https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm`), and the original Secret Tel Aviv Facebook publication (`https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/`).

**Window 3: 2D_Part_Orienting.cpp**
Themed like a classic IDE or Notepad window with a stark white background and monospace font. It outlines the C++ implementation within an open-source computational geometry library of an efficient algorithm to construct a 'push plan' for orienting polygons. A hyperlink at the bottom points to additional info and code at `https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/`.

**Window 4: The_Turing_Jest.exe**
Styled as a vintage mIRC chat client window. The "chat logs" describe the LMSYS-like arena where LLMs compete in making and explaining puns, rated by users. A chunky, 90s-style "Join Server" button links directly to the arena at `https://jest.geekip.dev`.

**Window 5: Rhymes_of_Israel.cab**
Designed as a classic Windows 95 "Installation Wizard". The prompt text details a Chrome extension utilizing an LLM to rewrite Israeli news headlines into comedic, highschool yearbook-style rhymes. An "Install Now..." button acts as a hyperlink to the Chrome Web Store: `https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb`.

**Window 6: Hatul_Basak.game**
Built with the visual charm of classic Windows games like Minesweeper. It describes a Hebrew port of catfishing.net—a Wikipedia-based Trivia game utilizing AI to generate daily challenges, alongside themed user-created puzzles. A button styled like a new game trigger links to `https://hatulbasak.geekip.dev`.

**Window 7: Portfolio_Project.html**
A highly meta "View Source" Notepad window, presenting the very website the user is currently browsing. It explains the project as an AI-generated, self-referential design experiment and contains a recursive hyperlink pointing back to `https://geekip.dev`.

**Window 8: Network_Neighborhood**
A small, neat File Explorer window containing three pixelated shortcut icons representing a GitHub Octocat, a LinkedIn logo, and a Facebook logo. These serve as direct social hyperlinks to `github.com/gevak`, `linkedin.com/in/gevakip`, and `facebook.com/geva.kipper`.

Anchoring the bottom of the screen is the iconic grey Windows Taskbar. On the far left is an interactive "Start" button. The middle recessed section of the taskbar features pixelated text serving as the footer credit: "Created and designed by AI." On the far right, inside the recessed 'System Tray' where the time normally sits, there is a live, ticking digital stopwatch. Powered by JavaScript, this clock calculates and continuously updates the exact number of hours, minutes, and seconds that have elapsed since the timestamp `2026-07-30 01:49:13`.
