The overall aesthetic of the website merges modern, elegant "glassmorphism" with a high-fidelity retro-futuristic "Cyber-Tamagotchi" theme. The color palette features a deep, dark-mode background (midnight blue and charcoal) accented by vibrant neon vectors (cyan, magenta, and electric lime) that pulse and change color as the page state evolves. The typography pairs a sleek, ultra-modern sans-serif for headings with a monospace terminal font for interactive elements and data points. 

At the core of the UI is a fixed, sticky center-screen element: a translucent, frosted-glass Tamagotchi device shell. Inside its digital screen lives the "Pet"—a smooth, 3D-rendered geometric entity. When the page loads, the pet is a simple glowing data-egg. The page layout is a vertical timeline that flows behind and around this central sticky device. As the visitor scrolls down and interacts with the content boxes, a progressive "XP Bar" on the Tamagotchi screen fills up, triggering scroll-driven JavaScript animations that cause the pet to hatch, grow, and evolve into increasingly complex, multifaceted shapes. Hovering over different project boxes sends unique animated "food" (data packets, musical notes, or polygons) into the Tamagotchi screen, which the pet eats to trigger unique reaction animations.

The Hero Section sits at the very top, fading in with a soft blur effect. It features large, elegant typography displaying the name: "Geva Kipper". Beneath it, a clean, single-sentence sub-heading reads: "Currently shaping the future of scalable infrastructure and software solutions as a Software Engineer at Google." Below this, a typewriter-effect monospace subtitle flashes: "SYSTEM NOTE: This website is re-designed each day by AI and is thus ever-changing."

The main content is divided into a staggered, dual-column winding path of eight frosted-glass content boxes. As they enter the viewport, they float into place using scroll-triggered CSS transforms. 
Box 1 introduces "GlglStats", featuring a background motif of LZ77 compression waveforms and music notes. It includes the description of the Israeli pop-chart repetitiveness Python project, a stylized button linking to https://glglstats.geekip.dev, and an embedded video thumbnail linking to the PyData TLV presentation at https://www.youtube.com/watch?v=jrKAtOsj1Lo. 
Box 2 presents "Ahuzat Dibuk", styled with a subtle, animated heat-map background. It details the Python scraping and data visualization for Tel-Aviv parking lots, accompanied by news links to Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/) and Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), plus the Secret Tel Aviv Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/). 

Box 3 details "2D Part Orienting", utilizing a background of slowly rotating wireframe polygons. It explains the C++ computational geometry push-plan algorithm and includes a link to the code and info at https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/. 
Box 4 showcases "The Turing Jest", adopting a split-color theme representing an arena. It describes the LMSYS-like LLM pun competition and features a link to https://jest.geekip.dev. 
Box 5 highlights "Rhymes of Israel", styled like a torn piece of a high school yearbook over a digital newsfeed. It explains the LLM comedic headline Chrome extension and provides the installation link: https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb. 

Box 6 displays "Hatul Basak", featuring faint, floating Wikipedia puzzle pieces. It outlines the AI-generated Hebrew catfishing.net trivia port and links to play or create puzzles at https://hatulbasak.geekip.dev. 
Box 7 is highly meta, featuring an "infinite mirror" CSS visual effect inside the card to represent the portfolio website itself, with a self-referential link pointing to https://geekip.dev. 
Box 8 serves as the social hub, where the Tamagotchi reaches its final "Ultimate Form" evolution. It houses three glowing, holographic interactive icons linking to github.com/gevak, linkedin.com/in/gevakip, and facebook.com/geva.kipper.

The Footer anchors the bottom of the page in a minimalist terminal-style black bar. It contains a glowing neon text string reading: "Design and code generated dynamically by an AI Model." To the right of this text is a live, ticking JavaScript stopwatch styled like a digital alarm clock, actively counting up the exact hours, minutes, and seconds that have elapsed since the timestamp 2026-08-15 00:50:28.
