**Global Aesthetic and Layout Mechanics**
The website operates as an immersive, full-bleed single-page interactive experience using a deep, parallax space environment. The background is a rich radial gradient blending midnight blue, deep violet, and pure black, populated by multi-layered CSS-animated twinkling stars and subtle, slowly drifting nebulas. Instead of a traditional vertical grid, the page functions as a digital planetarium. The user scrolls downward, triggering an SVG line-drawing animation—a glowing, stardust-like tether that draws itself across the screen, connecting a series of eight distinct "stars" (nodes). This creates a massive, continuous constellation that maps out the developer’s skills and projects. The UI elements utilize "glassmorphism"—dark, frosted, semi-transparent panels with subtle glowing borders, ensuring the content is highly legible while allowing the cosmic background to shine through. Typography pairs a sleek, modern sans-serif for headings (evoking aerospace tech) with a clean, highly readable serif for body copy.

**Hero Section (The Zenith)**
The landing viewport centers on a brilliant, pulsing celestial body. Hovering over it in elegant, glowing text is the name: "Geva Kipper." Directly beneath the name is a crisp, single sentence: "Software Engineer at Google, shaping the future of information at a planetary scale." Below this, a slightly dimmer, italicized subtitle adds the site's unique hook: "This celestial map is re-designed each day by AI, ensuring an ever-changing digital universe." At the bottom of the viewport, a tiny shooting star loops downwards, serving as an intuitive call-to-action to begin scrolling into the constellation.

**The Constellation Nodes (Sections 1 through 4)**
As the scroll-triggered glowing line descends, it hits the first major star, expanding it into the **GlglStats** box. This panel features a faint background pattern resembling an audio waveform made of stars, representing the LZ77 compression algorithm. The text details the Python project measuring the repetitiveness of Israeli pop-chart songs. It includes two glowing, orbital buttons: one linking to the live site (https://glglstats.geekip.dev) and another to the PyData TLV YouTube presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo).

The line then zig-zags to the **Ahuzat Dibuk** node. This glass panel is underlit by warm, shifting colors (reds and oranges) to emulate an urban heat-map. The content introduces the Python scraping and data visualization project for Tel-Aviv parking lot occupancy. Links to the news coverage on Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/) and Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), alongside the Secret Tel Aviv Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/), are styled as interconnected satellite nodes that light up on hover.

Next is the **2D Part Orienting** box. The glowing tether forms a distinct geometric polygon as it reaches this star. The panel describes the C++ implementation within an open-source computational geometry library for constructing polygon push-plans. A sleek, terminal-like text link directs users to the code and additional info (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).

The fourth stop is **The Turing Jest**. Visualized as a binary star system (two stars orbiting one another to represent competing LLMs), this section introduces the LMSYS-like arena where AI models battle over making and explaining puns. A glowing, glowing-bordered button links directly to the arena (https://jest.geekip.dev).

**The Constellation Nodes (Sections 5 through 8)**
Continuing along the stardust trail, we reach **Rhymes of Israel**. This panel is framed by a faint, floating high-school yearbook motif drawn in starlight. It introduces the Chrome extension that uses an LLM to rewrite Israeli news headlines into comedic rhymes. A prominent, extension-styled button links directly to the Chrome Web Store installation page (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

The line sweeps across the screen to **Hatul Basak**, conceptualized visually as a swirling spiral galaxy of connected trivia facts. The text explains the Hebrew port of catfishing.net—a Wikipedia-based trivia game featuring AI-generated daily challenges and user-created themed puzzles. An interactive, glowing link invites visitors to play and build puzzles (https://hatulbasak.geekip.dev).

Penultimately, the line wraps into a subtle, infinite-loop graphic (a gentle space-time distortion) for the **Meta Portfolio** box. It humorously notes the self-referential nature of the project—presenting the very website the user is currently navigating. A recursive, echoing link points right back to itself (https://geekip.dev).

Finally, the constellation terminates at the **Observer’s Outpost** (Section 8). This node acts as a digital space station containing minimalist, neon-glowing SVG icons for GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper). Hovering over each icon creates a rippling "sonar" effect in the surrounding starfield.

**The Footer (The Temporal Horizon)**
At the absolute bottom of the cosmic map, the glowing line fades into the darkness, giving way to an elegant, center-aligned footer. The text proudly states: "Design and architecture conceptualized by an AI Model." Just below this is the site's temporal anchor: a sleek, monospaced digital stopwatch using JavaScript to actively tick upwards, displaying the exact hours, minutes, and seconds that have elapsed since the singularity point of `2026-08-17 00:51:57`.
