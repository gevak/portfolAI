**Overall Aesthetic & Theme**
The website is designed as a sleek, futuristic, glassmorphic "smart" vending machine set against a dark, cinematic background (midnight blue/charcoal). The machine features glowing neon accents in cyan and magenta. The interface relies on a mix of modern sans-serif typography (like Inter) for readability and glowing monospace (like Fira Code) for digital displays. The user interacts with the machine by "selecting a snack" (a project), which animates a dropping mechanism, delivering the project details into a dispensing tray that expands into an elegant modal window.

**Header: The Vending Machine Marquee**
At the top of the machine is a wide, glowing digital display board. 
*   **Main Title:** "Geva Kipper" in bright, bold, backlit lettering.
*   **Bio Screen:** An LED-style scrolling ticker below the name displaying: "Software Engineer at Google, currently working on [Insert single sentence about current work]."
*   **AI Warning Label:** A futuristic warning sticker in the top right corner that reads: "Notice: UI re-designed each day by AI. Ever-changing."

**The Interaction Mechanism**
The center of the page is the vending machine’s glass window, displaying a 4x2 grid of "snacks" sitting on metal coils. 
Hovering over any snack triggers a subtle 3D tilt effect and highlights it with a localized glow. Clicking a snack spins the CSS-animated metal coil behind it. The snack visually drops down to the bottom "Dispenser Tray." Once it hits the tray, the tray slides open, expanding into a sleek, translucent glassmorphic overlay over the machine. 

**The Dispenser Modal ("Nutritional Facts")**
When the project overlay opens, the details are presented like the back of a snack wrapper. The project description forms the "Ingredients," and the external links form a barcode or a "Nutritional Facts" table. 

**The 8 "Snack" Boxes (The Grid)**
*   **Box 1 (GlglStats):** Designed as an energy bar with a cassette-tape graphic. 
    *   *Description:* A Python project measuring repetitiveness of Israeli pop-chart songs based on LZ77 compression, visualizing repetition patterns in famous songs.
    *   *Links:* A primary button linking to `https://glglstats.geekip.dev` and an embedded iframe/thumbnail playing the PyData TLV presentation: `https://www.youtube.com/watch?v=jrKAtOsj1Lo`.
*   **Box 2 (Ahuzat Dibuk):** Designed as a chocolate bar wrapped in a miniature parking ticket.
    *   *Description:* Python scraping and data visualization project collecting statistics on Tel-Aviv car parking lots occupancy, generating heat-maps for residents.
    *   *Links (Styled as "News Sources"):* Links to 13tv (`https://13tv.co.il/item/news/domestic/internal/parking-902956407/`), Mako (`https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm`), and the Secret Tel Aviv Facebook post (`https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/`).
*   **Box 3 (2D Part Orienting):** Designed as a rigid, origami-folded chip bag featuring geometric wireframes.
    *   *Description:* C++ implementation in an open-source computational geometry library of an efficient algorithm for constructing a 'push plan' to orient a given polygon.
    *   *Links:* Code and info button linking to `https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/`.
*   **Box 4 (The Turing Jest):** Designed as a classic, colorful joke-shop candy box.
    *   *Description:* An LMSYS-like arena where LLMs compete at making and explaining puns, rated by users.
    *   *Links:* A "Play Now" button linking to `https://jest.geekip.dev`.
*   **Box 5 (Rhymes of Israel):** Designed as a pack of chewing gum wrapped in a satirical newspaper print.
    *   *Description:* A Chrome extension using an LLM to rewrite Israeli news headlines into comedic rhymes in the style of a highschool yearbook.
    *   *Links:* An "Install Extension" button to `https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb`.
*   **Box 6 (Hatul Basak):** Designed as a sleek, premium tin of cat food or a Japanese cat-themed treat.
    *   *Description:* A Hebrew port of catfishing.net, a Wikipedia-based Trivia game. Uses AI to generate daily challenges, alongside user-generated themed puzzles.
    *   *Links:* A prominent link to play and create puzzles: `https://hatulbasak.geekip.dev`.
*   **Box 7 (Portfolio Website):** Designed recursively as a transparent bag containing a tiny replica of the vending machine itself.
    *   *Description:* A meta portfolio website project—the exact site the user is currently viewing. 
    *   *Links:* A recursive self-reference link to `https://geekip.dev`.
*   **Box 8 (The Social Variety Pack):** Designed as a shiny, multipack bundle featuring distinct flavor icons. 
    *   *Description:* Developer profiles and networking.
    *   *Links:* Three stylized buttons (or flavor tabs) linking directly to `github.com/gevak`, `linkedin.com/in/gevakip`, and `facebook.com/geva.kipper`.
