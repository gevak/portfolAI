**Global Layout and Interaction Mechanics**
The website is a single-page, horizontally scrolling experience built on modern web technologies (utilizing scroll-hijacking via JS libraries like GSAP). As the user scrolls down their mouse wheel, the page translates this into horizontal movement, driving a sleek, minimalist platformer game. The visual style is elegant and modern—think of games like *Gris* or *Alto’s Adventure*—using high-contrast vector art, smooth parallax backgrounds, and glassmorphism UI elements rather than clunky retro pixels. The "hero" is a stylized, silhouetted avatar of Geva Kipper. The avatar automatically runs right as the user scrolls down, leaping over gaps, resting at checkpoints (the projects), and idling when the user stops scrolling.

**The "Start Screen" (Header Section)**
The site opens on a breathtaking, atmospheric landscape. In the center, sleek, modern typography displays the developer's name: **Geva Kipper**. Beneath it, a clean, single sentence reads: "Currently engineering impactful solutions and shaping digital experiences at Google." Floating just above the ground in a holographic, glowing font is the subtitle: *"This digital realm is re-designed each day by AI, ensuring an ever-changing landscape."* The avatar stands at the left edge of the screen, prompting the user to scroll to begin the journey.

**Level 1: The Sound Wave Caverns (GlglStats)**
As the avatar runs right, the landscape transitions into a cavern constructed from glowing equalizer bars and compressed data blocks. The "box" for this section is a massive, transparent glass monolith in the background. It projects a holographic interface presenting 'GlglStats'—the Python project measuring Israeli pop-chart repetitiveness via LZ77 compression. Interactive UI buttons float near the avatar: one linking to the live visualization (https://glglstats.geekip.dev) and a floating, glowing "Play" button that opens a modal playing the PyData TLV presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo).

**Level 2: The Neon Gridlock (Ahuzat Dibuk)**
The background parallax shifts to a futuristic, nighttime Tel Aviv skyline. The platforms the avatar runs across are stylized parking lot rooftops, glowing with heat-map colors ranging from blue to deep red to represent occupancy data. Floating billboards in the background describe 'Ahuzat Dibuk', the Python scraping and data visualization project. Scattered along the path are glowing tokens the user can click: two styled as news screens linking to the Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/) and Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm) features, and a third styled as a social beacon linking to the Secret Tel Aviv Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

**Level 3: The Geometry Factory (2D Part Orienting)**
The environment transforms into an abstract, kinetic factory filled with geometric polygons. Background elements actively demonstrate the algorithm, with robotic arms "pushing" chaotic shapes into perfect alignment. The avatar navigates over platforms made of perfectly oriented geometric shapes. A sleek, blueprint-style placard presents the C++ '2D Part Orienting' computational geometry project. A glowing portal acts as the link to the open-source code and additional info (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).

**Level 4: The Colosseum of Wit (The Turing Jest)**
The avatar enters a grand, ruined arena where two massive, glowing orbs (representing LLMs) float in the background, firing glowing text bubbles at each other. This is the LMSYS-like arena of 'The Turing Jest'. The project description is etched into a grand digital scoreboard in the center of the arena, explaining the pun-making competition. A golden ticket booth at the end of the platform provides the link to enter the arena and rate the jokes (https://jest.geekip.dev).

**Level 5: The Floating Newsroom (Rhymes of Israel)**
The sky clears, and the platforms become floating, folded newspapers and highschool yearbooks. The parallax background features comedic, rhyming headlines scrolling like ticker tape. The section introduces the 'Rhymes of Israel' Chrome extension, explaining how an LLM rewrites news sites into comedic rhymes. A giant, floating chrome orb with a puzzle piece acts as the interactive install button, linking directly to the Chrome Web Store (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

**Level 6: The Mystical Labyrinth (Hatul Basak)**
The scene transitions into an elegant, library-like maze where playful, shadowy cat silhouettes dart through the background. Giant, floating Wikipedia puzzle pieces serve as platforms for the avatar. A glowing magical tome presents 'Hatul Basak', explaining its nature as a Hebrew port of catfishing.net and its AI-generated daily challenges. A glowing doorway shaped like a cat’s head invites users to play and create puzzles, linking to the game (https://hatulbasak.geekip.dev).

**Level 7: The Fourth Wall (The Meta Portfolio)**
Suddenly, the polished graphics glitch slightly, stripping away to reveal the wireframes, CSS grid lines, and JS console logs of the website itself. The avatar runs along lines of code. This meta-level presents the portfolio website project you are currently viewing. A self-referential, glowing "infinity loop" icon floats above the avatar, linking back to the domain root (https://geekip.dev), representing the architectural blueprint of the site.

**Level 8 & The End Game (Socials and AI Footer)**
The avatar finally reaches a serene, mountaintop sanctuary—the classic "end of the level" trope. Instead of a castle, there is a sleek, modern command center. Three elegant, glowing flagpoles stand tall, flying minimalist banners for GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper). 

As the avatar stops at a glowing computer terminal on the summit, the final footer UI fades in over the sky. It features elegant, terminal-style text granting credit: *"World Architect: Designed and generated by AI."* Directly beneath this is a live, ticking digital stopwatch, styled as a high-score timer, meticulously counting the hours, minutes, and seconds that have elapsed since the epoch of **2026-08-16 00:53:39**, cementing the ever-changing, temporal theme of the site.
