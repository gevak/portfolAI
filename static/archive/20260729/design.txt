The website is styled as a full-screen, interactive Windows 95 desktop environment, blending nostalgic, retro-pixelated aesthetics with smooth, modern JavaScript interactions. The background is the classic solid teal (`#008080`), overlaid with a very subtle, modern CRT scanline effect. The content is divided into draggable, overlapping UI "windows" featuring classic off-gray (`#C0C0C0`) backgrounds, raised bevel borders, a dark blue title bar with an "X" close button, and MS Sans Serif typography. When users click different windows, they snap to the foreground via z-index manipulation. 

In the center of the desktop sits the primary profile window titled "System_Properties.exe". The header displays the developer's name, "Geva Kipper", in a bold, pixelated font beside a classic computer icon. Directly below is a clean text block reading, "Currently engineering solutions at Google." At the bottom of this window, styled as a retro yellow-triangle system warning, is the subtitle: "Notice: This operating system is procedurally re-designed each day by AI and is thus elegantly ever-changing."

The first project, 'GlglStats', is housed in a window styled like the classic Windows Media Player. It features a pixelated visualization of an audio waveform acting as the LZ77 compression heatmap. Below the technical explanation of Israeli pop-chart repetitiveness, there are two chunky, raised buttons: "Launch App" linking to https://glglstats.geekip.dev, and a "Play Video" button holding the YouTube PyData TLV presentation link (https://www.youtube.com/watch?v=jrKAtOsj1Lo).

The second project, 'Ahuzat Dibuk', is presented in an "MS Paint" style window titled "Parking_Occupancy.bmp". The window displays a colorful, pixelated heat-map canvas representing Tel-Aviv parking lots. The project's Python scraping and data visualization details are written in a classic toolbox sidebar. Raised UI buttons acting as "Color Swatches" serve as outgoing links to the news coverage on Channel 13 (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), Mako (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and the original Secret Tel Aviv Facebook post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

The third project, '2D Part Orienting', takes the form of an MS-DOS prompt or classic "Notepad" window. The background is stark black or crisp white with monospace text, detailing the C++ open-source computational geometry library and the push-plan algorithm used to orient polygons. A blinking cursor prompts the user to type or click the "Execute" link, directing them to https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/.

The fourth project, 'The Turing Jest', opens in a window resembling a classic chat client or IRC terminal titled "TuringJest_Arena.bat". The description explains the LMSYS-like arena where LLMs battle to make and explain puns based on user ratings. A "Connect to Server" button at the bottom provides a direct link to https://jest.geekip.dev.

The fifth and sixth windows utilize classic application tropes. 'Rhymes of Israel' is formatted like a Windows 95 Installation Wizard ("Setup.exe"), explaining how the Chrome extension uses an LLM to rewrite Israeli news headlines into high school yearbook-style comedic rhymes, featuring an "Install Now" button linking to the Chrome Web Store (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb). 'Hatul Basak' looks like a classic Windows Solitaire or Minesweeper window titled "Trivia.exe", detailing its nature as a Hebrew port of catfishing.net, boasting daily AI-generated challenges and user-created themed puzzles, with a "New Game" menu button linking to https://hatulbasak.geekip.dev.

The seventh window is highly meta, styled to look like an early version of Internet Explorer. The address bar displays https://geekip.dev, and the window's content cheekily breaks the fourth wall, showcasing the current portfolio site itself as an ongoing project, linking directly back to its own URL as a self-reference. 

The eighth structural box is a classic file explorer window titled "Network Neighborhood". Inside, large pixelated icons sit gracefully on a white background: a floppy disk icon linking to GitHub (github.com/gevak), a classic briefcase icon linking to LinkedIn (linkedin.com/in/gevakip), and a rolodex icon linking to Facebook (facebook.com/geva.kipper). 

Anchoring the single page is a classic, thick gray Windows 95 Taskbar locked to the bottom viewport edge. On the left is the iconic "Start" button. On the far right is the "System Tray" presented in an inset bevel. Instead of the standard volume controls, the tray text reads: "System Generated by: AI Assistant". Next to it sits a glowing, digital-green retro clock functioning as a live stopwatch, continually ticking to display the exact elapsed hours, minutes, and seconds since the timestamp `2026-07-29 01:57:31`.
