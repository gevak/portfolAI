The website is styled as a modern, glassmorphic mock operating system running entirely within the browser window. The single-page layout mimics a desktop environment with a slow-moving, abstract gradient background. The UI elements—taskbars and open application windows—are made of translucent frosted glass with soft drop shadows and thin, glowing borders, leveraging modern CSS backdrops and JavaScript for draggable, resizable windows.

At the top of the screen is the "System Menu Bar." The left side functions as the user profile, displaying the text: "Developer: Geva Kipper," followed by a sleek status indicator reading, "Currently engineering solutions at Google." The center of the top bar features a scrolling marquee or subtle pulsing text that serves as the subtitle: "System UI is dynamically re-designed each day by AI and is thus ever-changing." 

The main desktop area contains eight open "Application Windows," replacing traditional portfolio boxes. These windows are scattered in an overlapping but highly readable masonry layout upon load, and users can drag them around or bring them to the front by clicking. Each window has a native OS feel with a title bar (featuring macOS-style colored dots for close/minimize/maximize) and is themed specifically to its project:

**Window 1: GlglStats** is designed to look like a hybrid between a music player and a data terminal. The UI features a mini visualizer graphic representing LZ77 compression patterns over pop-chart data. It includes a prominent play button linking to the PyData TLV presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo) and a "Launch App" button linking to the live site (https://glglstats.geekip.dev).

**Window 2: Ahuzat Dibuk** mimics a radar or weather-map interface. The background of the window is a faint heat-map of Tel-Aviv. The interface displays data-scraping statistics and features three distinct "Media Report" icons: two linking to the news coverage (https://13tv.co.il/item/news/domestic/internal/parking-902956407/ and https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and a retro Facebook icon linking to the Secret Tel-Aviv post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

**Window 3: 2D Part Orienting** is styled as a CAD (Computer-Aided Design) or blueprint software window. It features a wireframe polygon graphic on a grid background. The text elegantly details the C++ push-plan algorithm implemented in the open-source computational geometry library. A "View Repository" button links to the project and code (https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/).

**Window 4: The Turing Jest** is themed as a split-screen arcade fighting game or a retro chatroom, symbolizing the LMSYS-like arena where LLMs battle. The window details how the models make and explain puns while users rate them. A glowing "Enter Arena" button links to the project (https://jest.geekip.dev).

**Window 5: Rhymes of Israel** is presented as a sleek browser extension marketplace page. It features a graphic of a traditional Hebrew newspaper that morphs into a comedic highschool yearbook page. An "Install Extension" button links directly to the Chrome Web Store (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

**Window 6: Hatul Basak** takes the form of a retro trivia terminal or a stylized Wikipedia page pop-up. It explains the Hebrew port of catfishing.net, highlighting the AI-generated daily challenges and user-themed puzzles. Dual action buttons are provided: "Play Game" and "Create Puzzle," both linking to the live application (https://hatulbasak.geekip.dev).

**Window 7: Meta Portfolio** looks like a system monitor or terminal window displaying an infinite mirror or wireframe version of the exact OS interface the user is currently looking at. It contains a self-referential description of the portfolio project itself, with a root link back to the domain (https://geekip.dev).

**Window 8: Network Settings** serves as the social links box. Styled as a network control panel, it shows three "connection ports" with large, elegant icons for GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper), each displaying a green "Connected" status light.

At the very bottom of the screen sits the "System Dock." The left side of the dock displays the system credits: "OS Architecture and Design generated by ChatGPT (AI Model)." The right side of the dock functions as the system clock, displaying a live JavaScript stopwatch ticking upward in hours, minutes, and seconds, measuring the exact uptime since the temporal anchor: 2026-08-10 01:11:23.
