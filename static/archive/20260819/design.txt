**Global Aesthetic and Layout Concept**
The website utilizes a modern, edge-to-edge dark mode aesthetic modeled after a mechanical Solari split-flap departure board found in vintage airports, fused with sleek, contemporary UI elements. The background is a deep charcoal or matte black. The primary visual engine of the page is a central grid of eight horizontal rows. Upon page load, an intricate JavaScript/CSS animation triggers: every character block on the screen rapidly cycles through random letters and numbers—cascading from top to bottom—before snapping into place with a simulated mechanical aesthetic to reveal the content. Typography heavily utilizes a monospaced, mechanical font (like Roboto Mono or Courier Prime) in bright yellow and crisp white against black split-flap tiles, paired with a clean sans-serif for expanded reading text.

**Header Section (The Terminal Signage)**
At the very top, designed like a glowing, backlit terminal header, the name "GEVA KIPPER" is displayed in large, bold, illuminated lettering. Directly below it, an elegant LED-style ticker displays the sentence: "Software Engineer currently solving complex problems at Google." Beneath this, acting as the terminal’s status warning, is a stylized subtitle in a contrasting color (e.g., alert orange) that reads: "NOTICE: This terminal's architecture is re-designed each day by AI and is thus ever-changing." 

**The Departure Board (Main Interactive Interface)**
The core of the single-page site is the 8-row departure board. Each row represents a "Flight" and is divided into columns: `DESTINATION` (Project Name), `CLASS` (Tech Stack), and `REMARKS` (Short hook). When a user hovers over a row, the flap tiles gently tilt. When clicked, the row smoothly drops down—mimicking an expanding terminal gate panel—to reveal a clean, modern content card containing the detailed description and interactive links.

**Footer and Timekeeping Element**
The bottom of the page features a persistent, fixed footer styled like a digital airport control console. On the left side, it displays a system credit reading: "SYSTEM OPERATOR: Designed and continuously routed by [Insert AI Model Name]." On the right side, a high-contrast, red LED-style digital stopwatch continuously ticks upward. This counter dynamically calculates and displays the exact elapsed time (Hours, Minutes, Seconds) ticking live since the timestamp: 2026-08-19 00:50:09, anchoring the ever-changing theme in a fixed point in time.
