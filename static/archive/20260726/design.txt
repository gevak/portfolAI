The visual layout of the single-page application is built around the concept of a **"Mendeleev Matrix"**—a beautiful, interactive CSS Grid designed to mimic the structure and aesthetic of the periodic table of elements. The entire page features a deep, elegant dark mode design (ebony and charcoal backgrounds) with glassmorphic elements and neon, color-coded accents that glow softly upon interaction. The periodic categories represent the programming languages and tech stacks used, driving the color scheme and grouping of the tiles.

At the very top of the page, acting as the "Metadata" of the table, sits the Header. Dominating the top-left in crisp, modern typography (like Inter or Roboto Mono) is the developer's name: **Geva Kipper**. Directly beside or beneath it is a sleek, muted badge containing the sentence: *"Software Engineer at Google, engineering planetary-scale solutions."* Below this, rendered in an intentionally glitchy or shifting matrix-style typography, is the subtitle: *"This interface is dynamically re-designed each day by AI; an ever-changing digital organism."*

The core body of the page houses the eight requested sections, stylized as massive, interactive **"Elemental Project Tiles."** Each tile possesses an Atomic Number (01 through 08), an elemental Symbol (e.g., 'Gl', 'Ad'), an Atomic Weight (representing lines of code or hours spent), and is color-coded by its dominant programming language category. When a user clicks a tile, it utilizes a smooth JavaScript transition to expand into a center-screen modal, dimming the rest of the table while revealing rich media, formatting, and hyperlinks.

**Tile 01: [Gl] GlglStats (Category: Python / Color: Azure Blue)**
The tile background features a faint, looping LZ77 compression algorithm visualization. When expanded, it reveals the project description measuring the repetitiveness of Israeli pop-chart songs. Inside, there is an embedded YouTube player linked to the PyData TLV conference presentation (https://www.youtube.com/watch?v=jrKAtOsj1Lo), alongside a sleek, neon-outlined call-to-action button linking directly to the live site at https://glglstats.geekip.dev.

**Tile 02: [Ad] Ahuzat Dibuk (Category: Data Visualization / Color: Emerald Green)**
Styled with an underlying animated heat-map representing Tel-Aviv parking occupancy. The expanded state presents the scraping project's lore. It features three distinct "Press & Media" isotope buttons: one linking to the Reshet 13 news story (https://13tv.co.il/item/news/domestic/internal/parking-902956407/), an icon for the Mako article (https://www.mako.co.il/nexter-news/Article-ae43964b891bf71027.htm), and a stylish Facebook icon pointing to the original viral Secret Tel Aviv post (https://www.facebook.com/groups/secrettelaviv/posts/10159636301195943/).

**Tile 03: [Po] 2D Part Orienting (Category: C++ / Color: Crimson Red)**
This tile uses a computational geometry aesthetic, featuring rotating wireframe polygons on hover. Expanding this element exposes the deep-dive technical explanation of the 'push plan' orientation algorithm integrated into an open-source library, wrapped with a direct launch-link out to the academic code repo at TAU: https://www.cgl.cs.tau.ac.il/projects/2d-part-orienting/.

**Tile 04: [Tj] The Turing Jest (Category: Prompt Engineering / Color: Amethyst Purple)**
The visual here balances artificial intelligence design with theatrical comedy masks. The tile expands to detail the LMSYS-like arena where LLMs battle over generating and decoding puns, rated by human consensus. An interactive, glowing "Enter Arena" button directs users to https://jest.geekip.dev.

**Tile 05: [Ri] Rhymes of Israel (Category: JavaScript / Color: Chrome Gold)**
This tile blends the rigid structure of Israeli news tickers with the playful, nostalgic aesthetic of a high school yearbook. Expanding it explains the LLM-powered Chrome extension functionality. The prime interaction inside is a custom-designed installation button mirroring the Chrome Web Store aesthetic, hyperlinked to its official listing (https://chromewebstore.google.com/detail/eainginjgdkpgolpjniijdihfbeeeklb).

**Tile 06: [Hb] Hatul Basak (Category: AI Scripts / Color: Wikipedia Silver)**
Featuring a subtle, pixel-art cat silhouette woven into a Wikipedia-style globe logo. The modal view highlights that this is a Hebrew port of catfishing.net—an AI-generated Wikipedia trivia game. It prominently displays two interactive portals: one to play the daily challenge, and another to author custom-themed puzzles, both funneling to https://hatulbasak.geekip.dev.

**Tile 07: [Pt] Portfolio Site (Category: Meta / Color: Translucent Glass)**
This box features a recursive, "Droste effect" visual—a miniature wireframe of the exact page the user is currently viewing. It cleverly remarks on the meta-nature of the project being displayed within itself, complete with a self-referential hyperlink loop tracking back to https://geekip.dev.

**Tile 08: [Sb] Social Bonds (Category: Noble Gases / Color: Titanium White)**
Acting as the final structural anchor of the periodic table, this tile doesn't expand into a project modal. Instead, hovering over it causes the tile to split chemically into three distinct atomic nuclei—each serving as a direct, highly stylized external link to GitHub (github.com/gevak), LinkedIn (linkedin.com/in/gevakip), and Facebook (facebook.com/geva.kipper).

Anchoring the entire experience is the **Footer Canvas**. Fixed firmly across the bottom viewport, it reads: *"Architected & Synthesized by AI"* on the lower-left. On the extreme lower-right sits a digital, monospace, pulsating stopwatch. Powered by JavaScript, it continuously ticks upward, calculating and outputting the exact Hours, Minutes, and Seconds that have elapsed since the temporal anchor point of **2026-07-26 02:06:07**.
